Cette plateforme e-commerce permet aux utilisateurs de parcourir un catalogue de produits, gérer un panier, passer des commandes. Elle comprend également un espace d'administration pour la gestion des produits, des catégories et des sous-catégories.

:hammer_and_wrench: Stack technique
Frontend

React
Redux (gestion d'état)
React Router
Axios
CSS / Bootstrap
Backend

NestJS
MongoDB (Mongoose)
JWT (authentification)
Class Validator / Class Transformer
:inbox_tray: Installation
Cloner le dépôt :

bash
git clone https://github.com/votre-utilisateur/nom-du-projet.git
cd nom-du-projetInstaller les dépendances du backend :

bash
cd backend
npm installInstaller les dépendances du frontend :

bash
cd ../frontend
npm install

:rocket: Démarrage
Backend (NestJS) :
bash
cd backend
npm run start:devLe serveur démarre sur http://localhost:3000
Frontend (React) :
bash
cd frontend
npm start
